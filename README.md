# Bottle Rocket Nozzle Analysis



##### \[About]



This project is an analysis of different bottle rocket nozzle geometries using CAD, OpenFOAM CFD, and empirical data. This project is developed in part to be a science fair project, while also being reproducible and accessible to the public for any use within the terms of the GPL-3.0 license.



##### \[IMPORTANT]



This project is currently a work in progress. Information, citations, files, and contents of this project may be incomplete and subject to change at any point in time. If there are any concerns or questions in regards to this project, please feel free open an issue in this repository. I'd love to hear feedback and constructive criticism.
