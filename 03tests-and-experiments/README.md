This folder will contain every single experiment segmented off into separate folders within this subfolder. It will the be broken off into attempts, with more than one existing in the case of failure or invalidation. Each of the attempt folder will have all the materials and files required for the experiment, and a small lab report detailing the instructions for each attempt. The digital simulations will have the FreeCAD file, the model used in the OpenFOAM simulation (if applicable), the raw data from the OpenFOAM simulation, the Python + Jupyterlab differential equation analysis, and the Paraview visualization of said file. The actual experiments will have relevant figures, diagrams, photos, and raw empirical data collected from devices, and the Python + Jupyterlab differential equation analysis.
